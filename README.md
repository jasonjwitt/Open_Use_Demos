# CSV to Report - Legacy System Data Reporting

This repository demonstrates how to automate the processing of legacy system data (CSV format) and generate reports and visualizations using Python.

## Purpose
The script in this repository reads legacy system data stored in a CSV file, processes the data by aggregating values by category, and then generates a report and a visualization (bar chart) of the aggregated data. The data is processed using Python libraries like Pandas for data manipulation and Matplotlib for visualization.

This repository is ideal for demonstrating how legacy system data can be modernized using Python without the need for complex overhauls, providing flexibility for reporting and analysis.

## Files in this Repository

- **CSVtoReport.py**: The main Python script that processes legacy data, aggregates values, generates the report, and visualizes the results.
- **legacy_data.csv**: The input file containing sample legacy system data in CSV format.
- **expected_report.txt**: A sample of the report that will be generated by the script after processing the input data.
- **expected_graph.png**: A sample bar chart generated by the script, visualizing the data.
- **requirements.txt**: Contains the list of dependencies needed to run the script. You can install them by running `pip install -r requirements.txt`.

## How to Use the Script

1. **Clone this repository**:
    ```bash
    git clone <your_repo_url>
    cd <your_repo_directory>
    ```

2. **Install dependencies**:
    Create a virtual environment and install the required packages.
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the script**:
    ```bash
    python CSVtoReport.py
    ```

4. The script will:
    - Read the input file `legacy_data.csv`.
    - Aggregate data by category (e.g., "Sales" and "Refunds").
    - Generate a text report saved as `report.txt`.
    - Save a bar chart as `sales_refunds_plot.png`.

## Explanation of the Code

The script uses `pandas` to read and process the data and `matplotlib` to create a bar chart of the aggregated values. The process includes:

- **Reading the CSV file** using `pandas.read_csv()`.
- **Aggregating data** by grouping by category (Sales, Refunds).
- **Generating a report** that lists the aggregated values.
- **Plotting a bar chart** of the sales and refunds data.
  
### Why Use a Custom Solution Instead of Pandas?

While using a built-in library like `pandas` could make the process faster and simpler, we opted for a more flexible approach. By writing a custom script:

- We can demonstrate the step-by-step process of reading, processing, and visualizing data from legacy systems.
- This approach shows how Python can be used for legacy system modernization without requiring an overhaul of the entire system.
  
In cases where specific flexibility and control over the data transformation process are required, custom code is often preferable.
